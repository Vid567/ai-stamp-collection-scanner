User Guide — Browser Beta v1.0

A practical guide to adding photos, creating an inventory, reviewing the records and saving your work.

1. Purpose

The Browser Beta provides an editable, photo-linked stamp inventory workflow. Details start as unknown and remain available for manual review.

2. Add photos

JPG/JPEG, PNG and WebP are supported. Each upload receives its own photo number, even if filenames are the same. One inventory can contain up to 20 photos.

3. Create the inventory

Open the AI Stamp Scanner, select your photos and choose Create inventory. The Beta creates one starting record for each photo. It does not automatically detect how many stamps are present.

4. Multiple stamps in one photo

If a photo contains multiple stamps, use Add record or Duplicate to create the additional records. Keep the correct source photo selected for each record.

5. Review and edit

Enter or correct the stamp details manually. If a record is linked to the wrong source photo, change the source photo.

6. Local storage and privacy

Photos and draft inventory data stay locally in your browser. Nothing is uploaded to a server. Browser storage can be cleared, so save completed work regularly as an Excel or CSV file.

7. Save your inventory

You can save the inventory as an Excel or CSV file. Both contain Record ID, Photo Number, Original Filename and Image Reference. Photos and thumbnails are not embedded in Excel in Browser Beta v1.0.

The Browser Beta is designed as a simple browser-based inventory workflow. Excel and CSV are export formats, not the application itself.

Limit: Browser Beta v1.0 does not automatically identify stamps and does not determine value, rarity, authenticity, watermark, exact perforation or catalogue number.
