Frequently Asked Questions

Short answers about privacy, supported photos, inventory creation and export in Browser Beta v1.0.

Does the scanner run entirely in the browser?

Yes. The Browser Beta runs locally in a modern web browser. No Python or other software installation is required.

Are my photos uploaded?

No. Photos stay locally in your browser and are not sent to an external server.

Does the scanner automatically identify stamps?

No. Browser Beta v1.0 is an inventory workflow. Stamp details remain available for manual review and editing.

Does the scanner determine value or rarity?

No. The app does not provide an appraisal and does not determine value, rarity, authenticity, watermark, exact perforation or catalogue number.

What happens if one photo contains multiple stamps?

Create inventory creates one starting record per photo. Use Add record or Duplicate to create a separate record for each additional stamp in that photo.

Which file formats are supported?

JPG/JPEG, PNG and WebP.

Can I save my inventory?

Yes. You can save the stamp inventory as an Excel or CSV file.

Are the photos included in the Excel file?

No. Browser Beta v1.0 stores text references only, including Record ID, Photo Number, Original Filename and Image Reference. Photos and thumbnails are not embedded in Excel.

Browser Beta v1.0 helps you organise a photo-linked stamp inventory. Unknown details require manual review.
