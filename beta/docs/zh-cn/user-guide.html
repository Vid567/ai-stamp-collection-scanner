用户指南 — Browser Beta v1.0

1. 用途

Browser Beta 可帮助您在照片中找到可见邮票，并创建与来源照片关联的可编辑清单。用户仍需检查自动生成的结果。

2. 添加照片

支持 JPG/JPEG、PNG 和 WebP。每次上传的照片都会获得自己的照片编号。每份清单最多可包含 20 张照片。

最佳照片应从正上方拍摄、清晰、光线充足，并确保每枚邮票完整可见。不要让散放的邮票互相重叠，因为被遮挡的部分无法可靠识别。

3. 创建清单

打开 AI Stamp Scanner，选择照片，然后点击创建清单。检测器会尝试分别找到每枚可见的实体邮票。

4. 多枚邮票和重复邮票

如果照片中有多枚邮票，扫描器会尝试检测多个对象。相同或相似的邮票之后可能按同一类型归组，并显示数量 2、3 等。请检查每枚实体邮票是否都被计入。

5. 检查和编辑

将清单与来源照片进行比较。对于密集页面、旋转邮票、暗光照片和重叠邮票，请特别仔细检查，并在需要时补充或修正信息。

6. 隐私

照片和临时清单数据保留在您的浏览器本地，不会上传到服务器。浏览器存储可能被清除，因此请定期将完成的工作保存为 Excel 或 CSV。

7. 保存清单

您可以保存为 Excel 或 CSV。文件包含记录 ID、照片编号、原始文件名和图像引用。Browser Beta v1.0 不会在电子表格中嵌入照片或缩略图。

Browser Beta 不判断价值、稀有程度、真伪、水印、精确齿孔或目录编号。
