AI Stamp Collection Scanner

用户指南 — Browser Beta v1.0

本指南介绍如何拍摄合适的照片、使用自动检测、检查清单以及保存您的工作。

1. 用途

Browser Beta 可帮助您在照片中找到可见邮票，并创建与来源照片关联的可编辑清单。自动结果仍需要用户检查。

2. 添加照片

支持 JPG/JPEG、PNG 和 WebP。每次上传都会获得独立的照片编号，即使两个文件的名称相同也没有问题。每份清单最多可包含 20 张照片。

✓ 推荐

从正上方拍摄，画面清晰、光线充足，并确保每枚邮票完整可见。

△ 较难但可用

非常密集的集邮册页面、轻微倾斜、文字或邮戳可能增加检测难度。

✕ 不推荐

邮票堆叠或互相重叠。请将散放的邮票平放、彼此分开后重新拍摄。

为什么重叠会造成问题：如果一枚邮票的一部分被另一枚遮住，照片中就看不到它的完整轮廓。扫描器可能漏检，也可能把两枚邮票当成一个对象。

3. 创建清单

打开 AI Stamp Scanner，选择照片，然后点击创建清单。检测器会尝试分别找到每枚可见的实体邮票，并为检测到的邮票创建记录。

AI 识别（可选）

希望国家、年代、面值等信息自动填写，而不是显示"未知"吗？请在扫描页面顶部粘贴您自己的免费 Google Gemini API 密钥（前往 Google AI Studio 获取，无需信用卡）。密钥仅保存在您自己的浏览器中。以此方式填写的行会标记为"AI 建议"状态，和所有自动结果一样，仍需人工复核。

4. 多枚相同邮票

每枚可单独看见的实体邮票都应生成一条独立记录，即使多枚邮票外观相同。数量是可编辑的收藏者字段，不能代替对单个对象的检测。请始终将记录数量与照片进行比较。

5. 检查和编辑

将清单与来源照片进行比较。对于密集页面、旋转邮票、暗光照片和重叠邮票，请特别仔细检查。必要时添加缺失记录、删除错误检测或修正信息。

6. 本地存储、隐私和使用统计

邮票照片和临时清单数据会在浏览器本地处理，不会上传用于邮票识别。为改进测试版，可能会收集匿名使用统计信息。浏览器存储可能被清除，因此请定期保存 Excel 或 CSV 文件。

7. 保存清单

您可以保存为 Excel 或 CSV。两种文件都包含记录 ID、照片编号、原始文件名和图像引用。Browser Beta v1.0 不会在电子表格中嵌入照片或缩略图。

限制：检测并不意味着所有邮票都一定能被找到或准确识别。Browser Beta v1.0 不判断价值、稀有程度、真伪、水印、精确齿孔或目录编号。
