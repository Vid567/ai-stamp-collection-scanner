AI Stamp Collection Scanner

Inicio rápido — Browser Beta v1.0

Sigue estos pasos para crear, revisar y guardar tu primer inventario de estampillas.

Primero, toma una buena foto

✓ Buena

Toma la foto directamente desde arriba, bien enfocada y con suficiente luz. Mantén cada estampilla completamente visible y separada de las demás.

△ Difícil, pero utilizable

Una página de álbum muy llena, una foto ligeramente inclinada, o la presencia de texto y matasellos pueden funcionar, pero revisa el resultado con especial atención.

✕ No recomendada

Un montón de estampillas sueltas, giradas y superpuestas. Sepáralas y toma otra foto. Las partes ocultas no se pueden detectar de manera confiable.

  1. Abre AI Stamp Scanner.
  2. Selecciona una o varias fotos JPG/JPEG, PNG o WebP.
  3. Verifica que cada foto reciba un número de foto.
  4. Selecciona Crear inventario. El escáner intenta encontrar por separado las estampillas visibles.
  5. Verifica el número de estampillas detectadas. Agrega un registro que falte o corrige un error cuando sea necesario.
  6. Revisa y edita los detalles y la foto de origen.
  7. Guarda el inventario como archivo Excel o CSV.

Importante: Incluso con una buena foto, Browser Beta puede no detectar alguna estampilla. Revisa siempre el inventario creado antes de guardarlo.

Las fotos permanecen localmente en tu navegador. El escáner no determina el valor, la rareza ni la autenticidad.
