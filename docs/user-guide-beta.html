AI Stamp Collection Scanner — Beta v1.0

User Guide

Purpose

Create an editable inventory while retaining the connection between every row and its source photo.

Photos

JPG/JPEG, PNG and WebP are accepted. Duplicate filenames are safe because every upload receives a separate Photo Number. One inventory can contain up to 20 photos.

Review

The scanner creates one manual-review row per photo. Add or duplicate rows when a photograph contains multiple stamps. Change the source-photo selector if a record is linked incorrectly.

Recovery and privacy

Draft data and photos are stored locally using browser storage. Nothing is uploaded. Browser storage can be cleared, so export completed work regularly.

Export

Excel is the primary export and CSV is the fallback. Both contain Record ID, Photo Number, Original Filename and Image Reference. Spreadsheet thumbnails are not embedded in Beta v1.0.

AI limitation: no external AI service is connected and no API key is exposed. Unknown details remain clearly marked. The scanner does not determine rarity, value or authenticity.
