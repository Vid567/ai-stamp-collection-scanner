AI Stamp Collection Scanner — Beta v1.0

Quick Start

  1. Open the Stamp Scanner.
  2. Choose one or more JPG, PNG or WebP collection photos.
  3. Confirm that each preview has a number such as Photo 001.
  4. Select Create inventory.
  5. Review every field. Unknown details remain marked for review.
  6. Add or duplicate rows when a photo contains multiple stamps.
  7. Export the finished inventory to Excel or CSV.

Photos stay in this browser. Automatic AI analysis is not connected in Beta v1.0. The scanner does not determine rarity, value, authenticity, watermark, exact perforation or catalogue identity.
