# AI Stamp Collection Scanner — Beta v1.0 Quick Start

1. Open `scanner.html` from the production website.
2. Choose one or more JPG, PNG or WebP stamp-collection photos.
3. Confirm that each preview has a permanent number such as Photo 001.
4. Select **Create inventory**.
5. Review every field. Unknown information deliberately remains marked for review.
6. Add, duplicate or delete records where a photo contains multiple stamps.
7. Select **Export to Excel** or **Export to CSV**.

Photos and draft inventory data stay in this browser. Automatic AI analysis is not connected in Beta v1.0; never paste an API key into browser code. The scanner does not establish rarity, value, authenticity, watermark, exact perforation or catalogue identity.
