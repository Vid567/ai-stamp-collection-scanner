# Shared brand system

AI Stamp Collection Scanner is the visual colour source of truth for this product family.

- Primary: `#14365E`; primary buttons, navigation emphasis, important links and headings.
- Secondary: `#41B6E6`; decorative accents, focus rings and large non-text highlights. Use a darker accessible blue for small text on white.
- Primary hover: `#0E2948`; primary pressed: `#091F38`; light accent: `#EEF5FB`.
- Background: `#F6F8FB`; surface: white; border: `#DCE5ED`.
- Cards use white surfaces and light blue-grey borders. Badges use light blue with navy text. Secondary buttons use light blue with navy text.
- Keyboard focus must remain visibly outlined. Success remains green, warning remains amber, danger/error remains red, and information uses accessible blue.
- Screenshots and stamp imagery must remain accurate. Regenerate marketing graphics only when obsolete interface branding is baked into pixels.
