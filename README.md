# AI Stamp Collection Scanner — Beta v1.0

Turn photos of a stamp collection into an editable, photo-linked inventory. Review every field and export the result to Excel or CSV.

![AI Stamp Collection Scanner](assets/marketing/premium/README-Banner-1600x500.jpg)

## Open the browser scanner

[Open AI Stamp Collection Scanner](https://vid567.github.io/ai-stamp-collection-scanner/scanner.html)

The normal Beta journey requires no Python, terminal or installation.

## Beta workflow

- Select one or more JPG, PNG or WebP photos.
- Give every photo a permanent Photo Number.
- Create editable inventory rows tied to their source photo.
- Add, duplicate, delete and correct records.
- Export all reviewed fields to Excel or CSV.
- Recover the current draft from local browser storage where available.

## Honest AI scope

Beta v1.0 does not expose an API key or send photos to an external AI service. Automatic AI analysis is therefore not connected. The manual inventory workflow remains fully usable and unknown information stays marked for review.

The scanner does not claim rarity, value, authenticity, watermark, exact perforation, catalogue identity or investment potential.

## Privacy

Photos and draft data stay in the browser. Users control when an export is created. Browser storage is not a permanent backup, so completed inventories should be exported.
